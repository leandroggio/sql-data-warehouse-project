# Proyecto de Analisis de datos y Data Warehouse

Bienvenido al repositorio del proyecto **Analisis de Datos y Data Ware House**

Este proyecto demuestra una solución integral de almacenamiento de datos y analítica, desde la construcción de un almacén de datos (data warehouse) hasta la generación de información práctica (actionable insights). Diseñado como un proyecto de portafolio, destaca las mejores prácticas de la industria en ingeniería y analítica de datos.

---

# 🚀 Requisitos del Proyecto

## Construcción del Data Warehouse (Ingeniería de Datos)

### Objetivo
Desarrollar un *data warehouse* moderno utilizando **SQL Server** para consolidar los datos de ventas, permitiendo la generación de reportes analíticos y la toma de decisiones informadas.

### Especificaciones
* **Fuentes de datos:** Importar datos desde dos sistemas origen (ERP y CRM) proporcionados como archivos CSV.
* **Calidad de datos:** Limpiar y resolver problemas de calidad de datos antes del análisis.
* **Integración:** Combinar ambas fuentes en un único modelo de datos intuitivo, diseñado para consultas analíticas.
* **Alcance:** Enfocarse únicamente en el conjunto de datos más reciente; no se requiere historización de datos.
* **Documentación:** Proveer documentación clara del modelo de datos para dar soporte tanto a los interesados del negocio (*stakeholders*) como a los equipos de analítica.

---

## BI: Analítica y Reportes (Análisis de Datos)

### Objetivo
Desarrollar análisis basados en SQL para obtener información detallada (*insights*) sobre:
* **Comportamiento del cliente**
* **Rendimiento de productos**
* **Tendencias de ventas**

Estos *insights* brindan a los *stakeholders* métricas clave del negocio, facilitando la toma de decisiones estratégicas.

> Para más detalles, consulta `02_docs/requirements.md`.
